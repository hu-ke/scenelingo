# Checklist

## 基础架构
- [x] 前端页面路由正常工作（首页 ↔ 审核页 ↔ 合并预览页）
- [x] React Context 状态管理正常运转（照片队列、当前索引、识别结果、已处理列表）
- [x] IndexedDB 增删查操作正常（保存照片、读取列表、删除单张）

## 首页功能
- [x] 可一次性选择多张本地照片（jpg/png/heic）
- [x] 点击上传后正确进入审核页，第一张照片开始识别
- [x] 已处理照片列表正确展示缩略图
- [x] 空状态时显示引导文案
- [x] 单张照片可成功删除
- [x] 多选 ≥2 张照片后"合并导出"按钮可用

## 审核页功能
- [x] 进入审核页后自动调用 `/api/recognize` 识别当前照片
- [x] 识别结果以矩形框 + 英文标签正确绘制在照片上
- [x] "重新识别"按钮可重新触发识别并刷新标注
- [x] 重新识别期间按钮处于加载状态，不可重复点击
- [x] "保存"按钮将照片存入 IndexedDB，自动进入下一张
- [x] "跳过"按钮丢弃当前照片，自动进入下一张
- [x] 全部照片处理完毕后显示完成提示，可返回首页
- [x] 进度指示器显示当前照片序号（如 "第 2/5 张"）

## 合并预览与导出
- [x] 合并页面可正确展示多张照片拼合的预览效果
- [x] 合并后的大图保留了各照片上的英文标识
- [x] "下载导出"按钮可触发浏览器下载 PNG 文件
- [x] 少于 2 张时给出提示，不允许进入合并页
- [x] 可从合并页返回首页

## 边界情况
- [x] 识别接口返回空结果时，标注区域显示"未识别到物体"提示
- [x] 识别接口报错时，显示错误提示并提供重试
- [x] 上传非图片文件时给出提示
- [x] 上传超大图片时前端有合理的加载提示
